This directory contains all 52 catalog icons in Default, Gray, and Solid
styles, including each original light and dark variant (312 SVG files).
Original SVG geometry and colors are preserved. Website-only class and
accessibility attributes were removed and the SVG namespace was serialized
for standalone image use. Each viewBox is 0 0 40 40.
